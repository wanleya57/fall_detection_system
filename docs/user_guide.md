# 用户手册

## 快速开始

### 1. 开机启动

将已准备好的 SD 卡插入 K230 开发板，上电后系统自动启动。

启动画面会显示在 TFT LCD 上，系统进入实时检测模式。

### 2. 正常工作状态

- LCD 实时显示摄像头画面
- 无告警时画面正常显示
- 系统指示灯正常闪烁

### 3. 跌倒检测

当系统检测到疑似跌倒时：

1. LCD 画面叠加红色 "Fall Detected!" 标识
2. 蜂鸣器发出报警声
3. 事件视频自动保存到 SD 卡
4. WiFi 推送通知到手机/云端

### 4. 手动复位

跌倒告警触发后，按以下方式复位：

- **短按复位键**: 清除告警，恢复正常检测
- 系统自动冷却 10 秒后也会自动恢复

### 5. 查看事件记录

双击功能键可查看最近的事件记录，记录会显示在 LCD 上。

## 按键操作

| 按键 | 操作 | 功能 |
|------|------|------|
| 复位键 | 短按 | 清除告警，恢复正常检测 |
| 功能键 | 长按 | 开启/关闭视频录制 |
| 功能键 | 双击 | 查看最近事件日志 |

## 配置修改

编辑 SD 卡上的 `config.json` 文件，修改后重启生效：

```json
{
  "confidence_threshold": 0.6,
  "confirm_frames": 5,
  "cooldown_ms": 10000,
  "wifi_ssid": "YourWiFi",
  "wifi_password": "YourPassword",
  "mqtt_broker": "192.168.1.100",
  "mqtt_port": 1883
}
```

### 配置参数说明

| 参数 | 默认值 | 说明 |
|------|--------|------|
| video_width | 720 | 视频宽度 |
| video_height | 480 | 视频高度 |
| video_fps | 30 | 视频帧率 |
| confidence_threshold | 0.6 | 检测置信度阈值 (0.0-1.0) |
| confirm_frames | 5 | 连续确认帧数 |
| angle_threshold | 45.0 | 身体倾斜角度阈值 (度) |
| cooldown_ms | 10000 | 告警冷却时间 (毫秒) |
| alert_enabled | 1 | 是否启用告警 (1=启用) |
| buzzer_enabled | 1 | 是否启用蜂鸣器 |
| recording_enabled | 1 | 是否启用视频录制 |
| notification_enabled | 1 | 是否启用WiFi推送 |
| wifi_ssid | K230_AP | WiFi名称 |
| wifi_password | 12345678 | WiFi密码 |
| mqtt_broker | 192.168.1.100 | MQTT服务器地址 |
| mqtt_port | 1883 | MQTT服务器端口 |
| mqtt_topic | fall_detection/events | MQTT主题 |

## 远程监控

### RTSP 视频流

如果启用了 RTSP 服务，可通过以下方式访问：

```bash
# 使用 VLC 播放器
vlc rtsp://<设备IP>:8554/stream

# 使用 ffplay
ffplay rtsp://<设备IP>:8554/stream
```

### MQTT 事件推送

系统通过 MQTT 协议推送跌倒事件，消息格式：

```json
{
  "event_id": "E12345678",
  "timestamp": 1714567890123,
  "confidence": 0.92,
  "fall_angle": 65.3,
  "state": 2
}
```

订阅主题：`fall_detection/events`

## 事件视频

事件视频保存在 SD 卡的 `events/` 目录下，文件名格式：

```
event_<事件ID>.yuv
```

视频包含事件发生前后的画面，可使用 YUV 播放器查看。

## 故障排除

### 系统无法启动
1. 检查 SD 卡是否正确插入
2. 确认 SD 卡格式为 FAT32
3. 检查启动文件是否完整
4. 查看串口日志获取错误信息

### 摄像头无画面
1. 检查摄像头模组是否连接正确
2. 确认摄像头型号是否支持
3. 查看串口日志中的初始化信息

### 检测不准确
1. 调整 confidence_threshold 参数
2. 确认光照条件满足要求
3. 调整摄像头角度和位置

### WiFi 连接失败
1. 检查 WiFi 名称和密码
2. 确认 WiFi 信号强度
3. 检查路由器设置

### 告警无法复位
1. 尝试长按复位键 5 秒
2. 重新上电重启系统
3. 检查按键硬件连接
